# Архитектура

Первый срез реализован как Swift Package, нативное SwiftUI-приложение macOS 15+.

ScreenCaptureKit получает аудио выбранного приложения. Микрофон поступает отдельно через AVAudioEngine VoiceProcessingIO с системным эхоподавлением, отключённым AGC и минимальным ducking. Микрофон подключён к нулевому по громкости mixer: обработка рендерится, собственный голос не воспроизводится. Оба источника используют host clock. При ошибке voice processing запись не переключается молча на сырой микрофон. Видеокадры отбрасываются. Общая шкала времени основана на presentation timestamps. Последовательная аудиоочередь конвертирует PCM в 16 кГц mono; AudioChunkWriter атомарно сохраняет WAV по 8 секунд и остаток при остановке. Ошибка записи прерывает цикл, показывается пользователю, встреча остаётся прерванной.

SessionStore хранит JSON-манифест в Application Support с доступом 0700/0600. Задания распознавания опираются на сохранённые WAV. После перезапуска незавершённые встречи и WAV без записи в манифесте восстанавливаются; повреждение одной встречи не скрывает остальные.

LocalTranscriber запускает whisper-cli фиксированными аргументами с русским языком и моделью small. Логи направлены в файл, процесс ограничен тайм-аутом. Единственный последовательный worker обновляет текст и состояния сегментов. Остановка захвата не отменяет распознавание сохранённого. AVFoundation собирает M4A по временной шкале; исходники остаются.

Main-actor MeetingModel координирует запуск, остановку, обработку, экспорт и историю. Окно нельзя закрыть с незавершённой операцией без явной остановки записи. Индикаторы разделяют наличие потока и уровень звука.

Следующие срезы: КП/подсказки; сделка и календарь Битрикс24; MCP; отдельная опция OpenRouter. Контракт продукта: `docs/superpowers/specs/2026-11-02-sales-copilot-design.md`. Факт сборки и файловой проверки не доказывает качество живой встречи.

Переносимый комплект сотрудника: bundled Resources/Tools/whisper-cli и Resources/Models/ggml-small.bin имеют приоритет над developer-путями. Backend собирается статически с системными фреймворками, macOS 15 deployment target, armv8.2-a; внешняя Homebrew linkage запрещена упаковщиком. Все runtime-данные создаются отдельно в Application Support текущего пользователя.

Оформление: закреплённая зелёная полоса #24919B со знаком и названием Аксис Суфлёр; нижняя закреплённая подпись на фоне #3A4458 с публичными ссылками на консалтинг, платформу и обучение. Продукт «Модель» выведен владельцем из разработки и в активных ссылках не показывается. Обе полосы находятся вне прокрутки истории и транскрипции. Знак встроен в Resources, сетевой загрузки ресурсов нет. Нативные системные шрифты сохраняют читаемость элементов macOS. Источник палитры: фирменный канон axisconsult-brand. Иконка приложения AppIcon.icns встроена в bundle, содержит размеры от 16 до 1024 пикселей; векторный исходник воспроизводится scripts/generate-icon.swift.

Подписи источников «Микрофон» / «Звук встречи» отделены от голосов. LocalDiarizer выполняет итоговую локальную группировку через FluidAudio 0.12.4 и явно переданные CoreML-модели. Во время записи личности не обещаются. SpeakerProfile, SpeakerTurn и ручные назначения добавляются в JSON как необязательные поля для совместимости старых встреч. Имя задаёт пользователь; повторная обработка сохраняет ручные поправки и сопоставляет старые группы только при достаточном временном соответствии. Качество модели требует отдельного замера, запуск не равен точности.

PlaybackController воспроизводит только общую запись с сохранением временной шкалы, поддерживает паузу, позицию, громкость и семь скоростей 0,5–2× через AVAudioPlayer.enableRate. При отсутствии M4A сначала собирается полный архив; отдельный WAV не подменяет всю встречу. Воспроизведение блокируется при записи/запуске/остановке; перед стартом и сменой встречи старый плеер останавливается. PlaybackTimeline определяет все активные интервалы; TranscriptPanel подсвечивает одновременно звучащие фразы и отключает автопрокрутку при ручном чтении. Состояние интерфейса хранится в ObservableObject/StateObject для совместимости установленного Command Line Tools без SwiftUIMacros.

Локальные альфа-обновления используют одну постоянную идентичность в Keychain и designated requirement с идентификатором приложения и хешем сертификата. AppUpdater проверяет подпись, числовой номер сборки, идентификатор и arm64, копирует кандидат в закрытый каталог на том же томе. Отдельный подписанный AxisUpdater ждёт выхода приложения, повторно проверяет копию, сохраняет предыдущую версию и выполняет замену с откатом при ошибке. Application Support не изменяется. Автоматического сетевого канала доставки нет. Переход с ad-hoc требует отдельной установки; удержание разрешений проверяется на двух реальных сборках. Локальная подпись не заменяет Developer ID и нотариализацию. Ключ не включается в исходники и комплект сотрудника.
