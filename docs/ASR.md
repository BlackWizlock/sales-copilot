# Локальные модели речи

В настройках доступны Whisper Small, Whisper Medium, Whisper Large v3 Turbo и Parakeet TDT 0.6B v3. Все варианты в каталоге многоязычные и поддерживают русский; английские версии Whisper с суффиксом .en и английская Parakeet v2 не предлагаются. Факт поддержки русского следует из выбранных семейств моделей, качество конкретной встречи проверяется отдельно.

Модель загружается только по кнопке пользователя. При загрузке доступны ход выполнения и отмена. Действующая модель и файлы встреч сохраняются. Новая модель устанавливается в отдельный временный каталог, проверяется целиком и атомарно перемещается на постоянное место. После загрузки пользователь выбирает модель отдельно. Смена модели и языка во время записи и обработки блокируется. Скачать другую модель во время встречи можно, если доступен Интернет; распознавание текущей встречи продолжает использовать прежнюю модель.

Удалить из интерфейса можно только невыбранную модель из собственного каталога Models/ASR приложения, когда запись и обработка завершены. Перед удалением проверяются точный каталог владельца, канонические пути и всё дерево на отсутствие ссылок. Встроенная Small и общий каталог FluidAudio не удаляются. При удалении дополнительной копии Small встроенная либо ранее установленная стандартная Small заново проверяется и возвращается в список; действующая модель не меняется.

Язык распознавания хранится отдельно от языка интерфейса. Whisper принимает русский, английский или автоматическое определение. Parakeet v3 сам определяет язык, поэтому принудительная настройка Whisper к нему не применяется. Интерфейс показывает это явно.

## Доставка моделей

Источник Whisper: ggerganov/whisper.cpp на Hugging Face. Источник Parakeet: FluidInference/parakeet-tdt-0.6b-v3-coreml. По HTTPS запрашивается точная ревизия репозитория, затем список файлов той же неизменяемой ревизии. Каждый файл имеет ожидаемый размер и контрольную сумму: SHA-256 из LFS либо Git SHA-1 объекта blob для небольших служебных файлов. Проверяется содержимое вместе с заголовком Git blob, а не SHA-1 самого файла. Это проверка согласованности с опубликованной HTTPS-метаинформацией, не независимая подпись издателя модели.

Загрузчик ограничивает размер каждого файла, суммарный размер модели, время запроса и время загрузки. Перенаправления допускаются только на HTTPS, поскольку Hugging Face использует собственную сеть доставки. Небезопасные пути, повторяющиеся имена, файлы без контрольной суммы и слишком большой список файлов отклоняются. Запросы содержат только идентификатор общедоступной модели и пути её файлов; аудио в них не входит.

Полученные файлы находятся в Application Support текущего пользователя. Загруженные модели проверяются по сохранённой ведомости при следующем запуске. До завершения проверки ранее выбранной загруженной модели новая запись не начинает распознавание этой моделью. Встроенная Small остаётся частью подписанного приложения и доступна отдельно.

## Совместимость с VoiceInk

Приложение может по отдельной кнопке проверить имеющуюся Parakeet v3 в стандартном каталоге FluidAudio. Проверяются все файлы модели по контрольным суммам закреплённой ревизии. Если они совпадают, разрешено читать этот каталог без копирования. Запись, очистка и удаление чужого каталога не выполняются. При несовпадении нужно загрузить собственную копию модели в каталог Axis.

Встроенный загрузчик FluidAudio при ошибке может удалять кэш и скачивать модель заново. Поэтому рабочее распознавание загружает CoreML-компоненты явно и создаёт AsrModels напрямую. Во время распознавания сетевых загрузок и восстановления общего кэша нет. Короткий остаток менее секунды дополняется нулями до минимального входа Parakeet; шкала времени исходной записи сохраняется.

## Проверка

`ASRCatalogTests` проверяет состав каталога, русский язык, закрепление ревизии, наличие всех компонентов, контрольные суммы и файловые пути. Команда приложения `--verify-asr` проверяет имеющуюся Parakeet по метаданным источника, создаёт синтетическую русскую фразу голосом Milena, выполняет реальное локальное распознавание, проверяет ключевые слова и остаток 0,5 секунды, выводит время с первой загрузкой модели. Она не читает реальные встречи и не скачивает отсутствующие веса. Успешный синтетический прогон не является измерением точности реальной встречи.

Проверка 02.11.2026 на рабочем Mac: имеющийся общий каталог Parakeet v3 содержит 21 проверенный файл, 483103089 байт, ревизия `7dd20fe6b1797d35f5e3307e8b1732d9a178edfe`. Веса не скачивались, общий каталог не изменялся. Синтетическая русская фраза длительностью 9,31 секунды распознана с правильными словами о коммерческом предложении, стоимости 100 тысяч рублей и сроке 4 недели. Первый вызов с загрузкой CoreML занял 13,43 секунды, повторный с уже загруженной моделью 0,11 секунды. Остаток длительностью 0,5 секунды прошёл проверку временных границ. Эти числа относятся к синтетической проверке на данном Mac; живой созвон и прочие модели отдельно не измерялись.
