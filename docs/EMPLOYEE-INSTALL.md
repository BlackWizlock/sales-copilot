# Установка Axis Суфлёр сотруднику

Комплект прототипа A для MacBook на Apple Silicon (M1 и новее), macOS 15 и новее. Проверен на M4 Max/macOS 27; совместимость с более старыми MacBook и macOS требует отдельного теста. Intel в этот архив не входит.

## Передача и установка

1. Передайте сотруднику весь ZIP `AxisCopilot-macos-arm64`, например через AirDrop или внутренний файловый диск. Внутри: приложение со встроенными whisper-cli, библиотеками и русской мультиязычной моделью small, а также эта инструкция. Не передавайте папку встреч со своего Mac.
2. Распакуйте архив. Перенесите AxisCopilot.app в папку «Программы» текущего пользователя или общую «Программы». Сотруднику не нужны Homebrew, Xcode, Python, API-ключ или подписка. Требуется около 1 ГБ свободного места плюс запас для аудиозаписей.
3. Запустите приложение через Finder. Это внутренний прототип с локальной подписью, без Apple notarization. Если Gatekeeper заблокирует запуск, владелец Mac должен проверить источник архива и самостоятельно разрешить открытие в «Конфиденциальность и безопасность». Не отключать Gatekeeper целиком и не снимать quarantine массово.
4. При первом запуске записи разрешите микрофон, а в «Конфиденциальность и безопасность, раздел Запись экрана и системного звука» включите AxisCopilot. Эти разрешения выдаются отдельно на каждом Mac. Если потребуется, перезапустите приложение через системный диалог.
5. Обновите список приложений, выберите Zoom/Телемост/браузер, начните короткую тестовую встречу. Проверьте оба индикатора и текст, завершите запись, прослушайте M4A. До этой проверки не использовать прототип как единственную запись важного разговора.

## Данные сотрудника

Записи и тексты находятся только на его Mac: `~/Library/Application Support/AxisSalesCopilot/Meetings/`. В архиве нет ваших встреч, CRM-контекста и ключей. Встроенная модель общая, пользовательские данные раздельные. Централизованная синхронизация, управление доступом сотрудников и CRM пока не реализованы.

Нужен офлайн-доступ: после установки приложение распознаёт без подключения к сети. При обновлении полностью заменяйте приложение после завершения записи. Папку Meetings сохраняйте. После смены локальной подписи macOS может сохранить устаревшую привязку: удалите только AxisCopilot из списка разрешений, добавьте установленный экземпляр приложения заново и примените системный перезапуск.

## Для сборщика

`bash scripts/package-employee.sh` требует Swift CLT, CMake, coreutils, ffmpeg и голос Milena. Скрипт собирает статический whisper.cpp из исходников с проверенным SHA256 и baseline armv8.2-a, deployment target macOS 15; запрещает внешние динамические зависимости, добавляет модель с проверкой SHA256, выполняет реальное локальное распознавание через встроенный backend, подписывает приложение и создаёт ZIP с SHA256. Модель не включена в git.

Это облегчает передачу прототипа. Для беспрепятственной регулярной установки и обновлений нужен отдельный процесс Developer ID signing + notarization; учётная запись Apple Developer сейчас не подключена.
