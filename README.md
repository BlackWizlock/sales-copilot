# Axis Суфлёр

Локальный помощник для встреч и продаж консалтинга на Mac.

Планируемые функции: запись микрофона и системного звука, русская транскрипция, автоматические подсказки по КП и сделке Битрикс24, календарь Битрикс24, MCP для агентов и опциональный OpenRouter.

В `main` находится каркас и [описание прототипа](docs/superpowers/specs/2026-11-02-sales-copilot-design.md), bootstrap `171b734`. Реализация ведётся отдельно в локальном дереве `.worktrees/recording-prototype`. Его `STATUS.md` содержит записи о сборках приложения, проверке MCP и ограниченных сценариях CRM. Результаты и незавершённая приёмка принадлежат этому дереву; они не означают интеграцию в `main` или публичный выпуск. Корневой `STATUS.md` сохраняет историю bootstrap, актуальный журнал прототипа находится в указанном дереве.

Инструкции: [CLAUDE.md](CLAUDE.md), `AGENTS.md` является ссылкой на него. Текущая работа: [STATUS.md](STATUS.md). Контракты: [_standards/README.md](_standards/README.md).

Конфиденциальные материалы и аудиозаписи не входят в репозиторий.
