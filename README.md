# Axis Суфлёр

Локальный помощник для встреч и продаж консалтинга на Mac.

Планируемые функции: запись микрофона и системного звука, русская транскрипция, автоматические подсказки по КП и сделке Битрикс24, календарь Битрикс24, MCP для агентов и опциональный OpenRouter.

Сейчас созданы локальный каркас и [описание прототипа](docs/superpowers/specs/2026-11-02-sales-copilot-design.md). Независимая проверка описания не выявила существенных пробелов. Приложение ещё не реализовано. Удалённый приватный репозиторий создан, но первый коммит ожидает решения по проверке Jev.

Инструкции: [CLAUDE.md](CLAUDE.md), `AGENTS.md` является ссылкой на него. Текущая работа: [STATUS.md](STATUS.md). Контракты: [_standards/README.md](_standards/README.md).

Конфиденциальные материалы и аудиозаписи не входят в репозиторий.
